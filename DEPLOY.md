# Deploy HerHealth Frontend to Vercel

This folder contains only the frontend code, ready to upload to Vercel.

## Option 1: Connect GitHub (Recommended)

1. Push this `vercel-deploy` folder to a GitHub repository
2. Go to [vercel.com](https://vercel.com)
3. Click **Add New** → **Project**
4. Import your GitHub repository
5. Framework preset: **Vite**
6. Build command: `npm run build`
7. Output directory: `dist`
8. Click **Deploy**

## Option 2: Vercel CLI

```powershell
cd vercel-deploy
npm i -g vercel
vercel login
vercel --prod
```

## Important: Set Environment Variable

In the Vercel dashboard, go to **Settings → Environment Variables** and add:

| Name | Value | Environments |
|------|-------|--------------|
| `VITE_API_BASE` | `https://your-backend-url.com` | Production, Preview, Development |

Replace `https://your-backend-url.com` with your deployed FastAPI backend URL.

Without this, the dashboard API calls will fail because they default to `http://localhost:8000`.

## What's Included

- `src/` — All React components, pages, and logic
- `vercel.json` — Vercel build configuration
- `package.json` — Dependencies and scripts
- `vite.config.ts` — Vite configuration with API proxy
- `tailwind.config.js` — Theme colors and fonts
- `index.html` — Entry point
- `.env.example` — Environment variable template

## What's NOT Included

- `node_modules/` — Will be installed by Vercel automatically
- `dist/` — Build output, generated by Vercel automatically
- `.env` — Create this from `.env.example` with your production API URL
